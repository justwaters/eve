Eve is a free GitHub Actions workflow. Seven AI models read each pull request, and every serious finding is checked against the code before it is posted.

How she decides

  1. Eve reads the pull request's diff through the GitHub API. She never checks out its code.
  2. Seven models review it independently, and the largest merges their answers into one list.
  3. Every blocker and warning is checked against the real file. If the code a finding quotes isn't there, it's dropped. If it can't be proved, it's listed apart and never counted.
  4. What's left is rated by who could trigger it and what they already hold.

Turn her on

  1. Copy examples/eve.yml to .github/workflows/eve.yml.
  2. Add the secret NVIDIA_API_KEY to that repository. Secrets are per repository.
  3. Pin uses: to a commit, because the workflow runs with your secrets.
jobs:
  eve:
    uses: justwaters/eve/.github/workflows/review.yml@<commit>
    secrets:
      NVIDIA_API_KEY: ${{ secrets.NVIDIA_API_KEY }}

Comment @eve-fisni pause, resume or review on a pull request to control her. Set AI_REVIEW_ENABLED=false to turn her off.

Before you do

Your code is sent to NVIDIA. Each reviewed pull request's diff, title and description leave GitHub. Don't use Eve where code must stay in-house.

She is advisory. Don't make her checks required: a pull request's own text can try to talk a model out of a finding. A person decides what merges.

Cost. Free on public repositories. On private ones a review uses about 7 minutes of Actions time, plus your NVIDIA key's usage. Only the first 60,000 characters of a diff are reviewed.
